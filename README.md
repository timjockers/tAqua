# tAqua

<img src="assets/logo.svg" alt="tAqua Logo" height="250" align="right">

**tAqua** is an automated irrigation controller designed to run on a Raspberry Pi.

The project is divided into two main components:

### tAqua_Daemon

Hardware control and irrigation logic for the tAqua automated irrigation system.

[View tAqua_Daemon →](https://github.com/timjockers/tAqua_Daemon)

### tAqua_Web

Web interface and configuration for the tAqua automated irrigation system.

[View tAqua_Web →](https://github.com/timjockers/tAqua_Web)

## Status

tAqua is currently **under development**. The architecture and individual components are still evolving.
